# 📡 Integration Channels

This directory contains integration channels and microservices that connect external messaging platforms with the **Google ADK Chat Assistant**.

## Available Channels

| Channel | Directory | Description | Supported Modalities |
|---------|-----------|-------------|----------------------|
| **WhatsApp Cloud API** | [`whatsapp/`](./whatsapp/README.md) | FastAPI microservice integrating Meta WhatsApp Cloud API | Text, Voice Notes, Audio, Images, Documents |

For setup and development instructions, refer to the individual channel documentation:
- [WhatsApp Cloud API Guide](./whatsapp/README.md)
